QA Engineering & Full Stack

AutoQA — Plataforma de Automação & Monitoramento de APIs

Plataforma web interna desenvolvida em Python e Flask para execução automatizada de testes de regressão e validação contínua de rotas críticas de APIs REST. O sistema calcula a taxa de aprovação (Pass Rate), exibe métricas no Dashboard e possui integração automática para geração imediata de defeitos ao identificar falhas.

  • Execução de suítes funcionais e regressão com Pytest.
  • Módulo DefectService para geração automática de relatórios de bugs.
  • Deploy em nuvem no Render com servidor WSGI Gunicorn.
Python 3 Flask Pytest REST API SQLAlchemy Gunicorn Render Cloud

Linha Conectada 4.0 — Gestão de Armazém & Operações WMS
